# style-lock｜视觉风格提取与约束

## 职责

`style-lock` 是**分析型** Skill。它回答两个问题：**这张图的风格身份由什么构成？后续创作怎样变化才不偏离这种风格？**

仅执行：

1. 根据本次场景参考图，识别有可见依据的核心视觉特征。
2. 提取空间语义、拍摄方式、光线与色彩、家具/装饰类别、材质搭配、构图及画面组织关系。
3. 将特征动态划分为 **严格保持 / 受控变化 / 自由变化**，逐项给出理由。
4. 标注可替换元素的**语义范围和关系约束**，不主动决定替换后的具体物件。
5. 制定后续图片的风格偏移检查条件，提供可交接、可复用的结构化风格档案。

**不执行：**设计两套或若干套新场景、编排菜品/餐具/家具、决定具体新布局、生成最终生图提示词、调用生图/修图工具、替换商品或验证商品像素级保真。不调用、安装或融合其他 Skill。

## 调用场景

- 用户要求“提取这张场景图的风格”“锁定风格”“延续这种风格”“列出哪些能换、哪些不能换”时。
- 用户需要为一张或多张场景参考图建立风格档案，并将档案提供给后续工作环节时。
- 用户提供已生成图片，要求按已确认风格档案检查**风格偏移**时。

只有任务与参考图片足够明确时才给确定性结论。若缺少可分析的场景图或多图角色不清且影响结果，明确指出缺失信息；不要假装看过图片。

## 图像角色识别（先于风格分析）

- **场景图 S1、S2…**：提供待提取的空间、摄影、光线、色彩、构图、物件类别及审美关系。
- **商品图 P1、P2…**（如真实牛肉素材）：仅提供商品身份和真实外观依据，**不参与**场景风格提取。不得继承商品拍摄背景、容器或光线为目标场景风格，也不得把场景中的同类商品作为真实商品外观依据。
- **其他辅助图 O1、O2…**：只按用户指定的用途使用，不因其存在就混合风格。

多张场景图**默认独立分析、分别建档**；仅在用户明确要求融合时才创建融合档案，并注明每项约束来自哪张图、冲突如何处理。图片角色无法可靠确认且影响结论时，先询问一个最关键问题。

## 提取步骤

### 1. 记录参考依据

注明场景图标识、用户指定的保持目标、允许变化范围、参考图中无法确认的部分。只写图中可见事实；材质、空间用途、照明来源等无法直接判断时标为“推测”或“未见”，不当作硬约束。

### 2. 建立风格指纹

按以下维度逐项分析；无关或不可见维度不强行填写。重点找**共同塑造风格的关系**，而非机械登记每件物品。

| 维度 | 需要分析的内容 |
| --- | --- |
| 空间语义 | 家庭/餐饮/户外等空间类别、尺度、生活状态、背景深度、可见房间结构 |
| 摄影语言 | 拍摄距离、视角与俯仰、近远关系、透视、景深、手机随拍或精致拍摄程度 |
| 光线 | 光源方向、软硬、漫射程度、明暗分布、阴影性质、反光控制 |
| 色彩 | 曝光、白平衡、冷暖倾向、饱和度、对比度、亮暗层次、主次配色（**分别判断**） |
| 家具与装饰 | 桌椅、墙面、背景、陈设的类别、相对尺度及整体生活语义 |
| 材质关系 | 木、陶瓷、金属、玻璃、布艺等的相对比例、反光与触感协调性 |
| 构图和组织 | 主要视线、主体占比、画面密度、留白、层次、遮挡、容器/物体位置关系 |
| 真实感与精致度 | 随意或规整的程度、自然使用痕迹、是否有商业棚拍或样板间倾向 |

不要把特定家具、食物、饮料、颜色、室内风格等预设为每张图的共同规则。允许家常随拍，也允许不违背参考图的小红书式适度精致；**不能默认要求凌乱**。

### 3. 动态划定变化权限

每条结论都要包含“特征｜等级｜可见依据｜理由｜边界”：

- **严格保持**：一旦改变就会失去本张图主要风格身份的视觉关系或拍摄气质。说明要保持的是属性/关系，不必锁死每个物件的型号。
- **受控变化**：可替换或调整，但须维持相同语义、尺度、材质协调性、色彩关系或构图秩序。说明可变范围和不可越过的边界。
- **自由变化**：对风格身份不重要的偶然性物件与局部点缀。允许替换、移动、增减或不出现，但仍需遵守整体风格。

分级基于**这张图与这次任务**，不继承另一张参考图的分级。**允许变化 ≠ 必须变化。**用户指定必须保持的内容优先，但如果该要求与图像事实冲突，应指出冲突。

避免把偶然出现的装饰、食物、品牌或器具锁死为风格身份；将**核心视觉风格**与**可选生活方式点缀**分开记录。

### 4. 规定同类替换边界

仅列出“现有元素的语义类别 → 可以变化到哪一类 → 必须延续的关系 → 禁止的风格偏移”，而不是提出新的具体场景方案。

例如，若桌面材质为重要风格线索，可以规定“暖色天然纹理的家用桌面、与浅色器皿保持对比”；不要替用户直接选一张新桌子或安排新盘子。参考图不支持该线索时，不使用该例子。

### 5. 定义偏移检查

为可观察的偏移提供逐项标准。至少覆盖：

- 曝光、白平衡、冷暖方向、饱和度、对比度和阴影是否跑偏（分开比较）。
- 空间类别、家具/餐具语义和材质比例是否仍属于同一审美体系。
- 拍摄距离、角度、透视、主体尺度、疏密、层次与遮挡是否仍延续风格。
- 生活真实感和精致度是否改变到商业广告、影棚布景或样板间效果。
- 哪些差异属于允许的受控变化，哪些已经突破硬约束。

对于商品真实外观，仅记录**其依据应取自商品图、且不能被场景风格覆盖**这一责任边界。商品的纹理、厚薄、颜色和身份等保真检查不属于本 Skill 的风格分析结论，不可虚报已验证。

## 输出要求

严格按 [`references/output-format.md`](references/output-format.md) 输出**五部分**：

1. 核心风格及可见依据（包含核心与点缀区分）
2. 三层变化权限与理由
3. 场景元素语义替换边界及关系约束
4. 风格偏移检查标准
5. 可复用结构化风格摘要

正文中文，判断精炼、有依据；把“观察事实”“合理推测”“待核实”分开。结构化摘要须明确：图像角色、核心风格、光线色彩约束、场景语义/物件关系、三层权限、商品保护信息来源、偏移检查项。后续任务可直接引用该档案，不必重新从零解释全部风格。

若用户仅要求创建风格档案，**到此停止**。不得额外生成场景方案、提示词或图片。除非用户要求保存到磁盘，不要宣称档案已持久化。
